## 2. 验证方法

运行：

```powershell
& scripts/validate_shop_regions.ps1 `
  -ScreenshotDirectory 'D:\创新实践课程\jcc 截图\Screenshots'
```

脚本逐张检查：

1. 图片是否为 1920 × 1092。
2. 五个卡槽矩形的宽高是否为正数。
3. 每个矩形是否完整处于截图边界内。
4. 分辨率不匹配或区域越界时以非零状态退出。
