# S18「自然之力」18.4 数据字典

## 1. 目标与边界

本数据集服务于装备推荐、阵容匹配和阵容短板分析。当前可审计样本包含 41 个英雄、32 件装备（8 件基础装备、24 件成装）、27 个羁绊和 10 套经公开统计页面核验的阵容。后续扩充时沿用相同字段，不覆盖历史版本。

数据只来自公开网页，不访问网站禁止抓取的 `/api/` 路径。每条业务记录均保存赛季、版本、来源页面和采集时间；项目自行添加的角色标签会明确标记为 `project_annotation`。

## 2. 公共字段

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | 项目内稳定且唯一的标识 |
| `name` | string | 是 | 中文显示名称 |
| `season` | string | 是 | 赛季编号，本项目为 `S18` |
| `version` | string | 是 | 游戏版本，本快照为 `18.4` |
| `source_url` | string | 是 | 可人工复核的公开页面 |
| `collected_at` | string | 是 | ISO 8601 采集日期 |
| `verification_status` | enum | 是 | `verified`、`partial` 或 `project_annotation` |

## 3. `champions.json`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `cost` | integer | 英雄费用，范围 1–5 |
| `traits` | string[] | 羁绊 ID 列表，必须能在 `traits.json` 找到 |
| `skill_name` | string | 技能名称 |
| `role_tags` | string[] | 项目用于推荐算法的角色标签，如 `tank`、`carry` |
| `image_url` | string | 公开头像地址，仅作来源定位，程序不强依赖 |

## 4. `traits.json`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `category` | enum | `origin` 或 `class` |
| `levels` | object[] | 激活档位；未完整核验时保持空数组，不猜测数值 |

## 5. `items.json`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `kind` | enum | `component` 或 `completed` |
| `components` | string[] | 成装所需的两个基础装备 ID；基础装备为空数组 |
| `effect_summary` | string | 简短效果摘要；不保存大段网页原文 |
| `role_tags` | string[] | 适配方向，如 `tank`、`attack_speed`、`physical` |

## 6. `lineups.json`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `champions` | object[] | 阵容英雄及其定位、星级和推荐装备 |
| `champions[].champion_id` | string | 必须引用 `champions.json` 中的英雄 |
| `champions[].position` | enum | `front`、`middle` 或 `back` |
| `champions[].is_core` | boolean | 是否为阵容核心 |
| `champions[].target_star` | integer | 推荐追求星级 |
| `champions[].recommended_item_ids` | string[] | 推荐成装 ID，必须引用 `items.json` |
| `traits` | string[] | 阵容主要羁绊 ID |
| `meta_stats` | object | 公开页面统计快照，不同版本不可混用 |
| `meta_stats.avg_placement` | number | 平均名次 |
| `meta_stats.pick_rate` | number | 登场率，按来源页面展示值保存 |
| `meta_stats.win_rate` | number | 登顶率，0–1 小数 |
| `meta_stats.top4_rate` | number | 前四率，0–1 小数 |
| `meta_stats.sample_count` | integer | 统计对局样本量 |

## 7. 版本与质量规则

1. 所有跨文件引用必须存在，ID 不得重复。
2. 同一阵容及其引用的英雄、装备、羁绊必须属于同一赛季和版本。
3. 成装必须恰好引用两个基础装备；基础装备不得引用其他装备。
4. 统计数据必须带样本量和来源，不把项目推断冒充官方结论。
5. 页面更新后新建版本目录，例如 `s18_18_5`，禁止直接覆盖 `s18_18_4`。
6. 提交前运行 `python scripts/validate_sample_data.py`，校验失败的数据不得进入推荐服务。

## 8. 推荐算法使用约定

原型评分采用 0–100 分：阵容英雄匹配 45 分、装备适配 25 分、羁绊覆盖 20 分、公开强度 10 分。该权重是课程项目的可解释基线，不代表游戏官方结论；后续可用真实对局回放和用户反馈调参。

部分新增英雄的个人羁绊字段尚未逐个核验。遇到这类阵容时，推荐服务会在解释中明示，并临时用阵容成员覆盖率估算羁绊就绪度；不会把缺失字段直接当成零羁绊。
